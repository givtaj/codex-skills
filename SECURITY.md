# Security

The latest version on the default branch is supported.

Do not open a public issue containing credentials, private data, or exploit details. Prefer GitHub's private vulnerability reporting for this repository. If that option is unavailable, open a minimal issue requesting a private contact channel without including sensitive details.

Public skill contributions must not contain secrets, personal absolute paths, executable caches, hidden network dependencies, or instructions that expand authority beyond the user's request. The repository validator checks portable invariants; maintainers must still review behavior, dependencies, and supporting files before publication.
