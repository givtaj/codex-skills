# Creativity

## Terminal Wireframe Sketching

[`terminal-wireframe-sketching`](../plugins/terminal-wireframe-sketching/) turns a supplied sketch, screenshot, product or design context, workflow, or software architecture into a compact monospaced wireframe for confirmation. It preserves source structure, labels inference, and uses readable screen, flow, tree, or architecture notation.

Install it with:

```bash
codex plugin add terminal-wireframe-sketching@givtaj-skills
```
