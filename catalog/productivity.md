# Productivity

## Status Review Dashboard

[`status-review-dashboard`](../plugins/status-review-dashboard/) turns verified project or workflow evidence into a compact status review with source links, clear state distinctions, and next actions. It renders interactively when the host supports that capability and preserves the hierarchy in Markdown otherwise.

Install it with:

```bash
codex plugin add status-review-dashboard@givtaj-skills
```

## Central Projects Tracking

[`central-projects-tracking`](../plugins/central-projects-tracking/) creates validated portfolio snapshots and complete private local tracking websites from bounded Git facts and explicitly allowlisted evidence. Its four-view experience includes decision queues, search, activity, source boundaries, and privacy-safe Git change plans. Scanned repositories remain read-only; publication, deployment, and scheduling stay separate.

Install it with:

```bash
codex plugin add central-projects-tracking@givtaj-skills
```

## Loose Thread Finder

[`loose-thread-finder`](../plugins/loose-thread-finder/) recovers forgotten project intent, unfinished work, and stalled handoffs from bounded task history and repository evidence. It reconnects related task families, detects continuity gaps, and surfaces focused evidence-backed next actions. Reviews are read-only by default; scheduled runs stay quiet when nothing material changes.

Install it with:

```bash
codex plugin add loose-thread-finder@givtaj-skills
```
