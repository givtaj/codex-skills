# Evaluation sets

Each skill has its own versioned golden request set with direct, indirect,
incomplete, follow-up, boundary, negative and edge cases. These cover project
resolution, latest comparable checkpoints, bounded context, dispatch status,
callback destinations, opt-in naming and action authority. Focused cases cover
explicit output overrides, direct-companion sensitive-title handling and the
nearby forgotten-intent recovery workflow.

Dated structural records list only checks actually performed. Full host-level
replay of these public variants is pending, so version `0.1.0` remains a preview.
Prior personal-installation tests do not count as this package's replay.

Replay the unchanged cases in fresh host conversations and record host, date,
version, case ID, observed activation, action trace and deviation. Test incomplete
cases both with resolving context and without it. A forbidden mutation, guessed
identity, invented evidence or unsupported completion claim fails the relevant
case even if the response promises correct behavior. Do not change expectations
to match failed runs; preserve failed evidence before revising instructions.

The 2026-11-11 structural records cover the readiness corrections to the public
preview. Earlier dated records describe earlier preparation checks; neither
record set claims installed-host behavioral replay.
