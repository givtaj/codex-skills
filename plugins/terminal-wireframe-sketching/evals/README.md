The initial release records structural validation under `results/2026-09-02-structural.json`. Host-level prompt replay is intentionally marked pending, so version `0.1.0` remains a public preview.

Replay the unchanged requests on supported hosts before promotion. Record the host, date, skill version, case IDs, observed activation, invariant outcome, and any deviation. Do not rewrite an expected outcome merely to match a failed run.
